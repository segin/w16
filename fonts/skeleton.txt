# skeleton.txt - w16's stroke designs for its second raster font set
# (Courier, MS Serif, Small Fonts, Symbol, the DOS-box Terminal sizes).
# Original design for w16 (public domain, CC0 1.0). tools/fontgen.py
# rasterises each design into every size's cells (ARCHITECTURE.md 6.9).
#
# One character per line:   U+XXXX[/style] FRAME  COMMAND; COMMAND; ...
#   style   a variant for one style only: serif (MS Serif, Symbol), slab
#           (Courier), sans (Small Fonts, Terminal)
#   FRAME   what plain numbers in y mean: c fractions of the cap height,
#           x of the x-height, f the whole cell (0 bottom row, 1 top row),
#           n an accent's own box (fontgen places it)
# Coordinates: x 0..1 across the glyph's ink box (beyond it is clipped);
# y a number in the frame (0 baseline, 1 the frame's top; negative:
# fractions of the descender), or an anchor B (baseline), X (x-height),
# C (cap height), A (ascender), D (descender), or c.5 x.5 a.5 d.5 (a
# fraction of that height), with ^N / _N for N pixels up / down (X^2).
# Commands:
#   L x y x y ...           a polyline
#   E x0 y0 x1 y1 [a0 a1]   an elliptical arc in a box, degrees counter-
#                           clockwise from 3 o'clock (default: all of it)
#   D x y                   a dot (its bottom row at y)
#   F x0 y0 x1 y1           a filled rectangle; G (same) a filled ellipse
#   P x y x y ...           a filled polygon
#   K                       erase instead of drawing from here on
#   S x y [l|r|lr]          a horizontal serif at a stroke's end (not in
#                           the sans style); T x y [u|d] a vertical one
#   g U+XXXX x0 y0 x1 y1    another design drawn small in that box
#   R U+XXXX                another design drawn whole (then more strokes)
