; Microsoft Win32s 1.30c (tests/installers.sh): Microsoft Setup (_MSTEST,
; the "Microsoft Test Driver", MS*STF.DLL), whose script binds KERNEL's
; SetErrorMode by name (GetProcAddress, a non-resident name). Screens, as
; on 3.1: the welcome (Continue), "SHARE.EXE is not loaded" (OK), the
; target directory, the Windows system directory (Continue); the files
; (disks 2 and 3 read from ..\DISK2 and ..\DISK3), "Win32s files
; successfully installed." (OK); Freecell Setup (Continue), its path
; (Continue), "Freecell was successfully installed." (OK); "Setup will
; now exit and restart Microsoft Windows" (Continue): Windows ends,
; _MSRSTRT.EXE and _MSSETUP.BAT run, Windows comes back with the "Win32
; Applications" group. Win32s needs virtual memory (a paging file): without
; one Setup says "Win32s requires Virtual Memory" instead of the SHARE box
; and then "Microsoft Win32s System Setup has failed."
; dest %WINDIR%/SYSTEM/WIN32S
; expect %WINDIR%/SYSTEM/W32SYS.DLL %WINDIR%/SYSTEM/WIN32S/W32S.386 WIN32APP/FREECELL/FREECELL.EXE
